# InsightLab — Identidade minimalista

Nova logo `insightlab-logo.svg` inspirada na proposta de painéis de dados. 40 ícones SVG independentes em `insightlab_mvp/assets/icons-minimal`. Paleta: roxo #8057E3, verde #8FD84A, amarelo #F9D354, base preta.

O arquivo `icons-ui.js` foi ajustado para SVG. Nenhum arquivo do backend, ambiente virtual ou start.bat foi alterado. Os PNGs anteriores permanecem no ZIP como fallback.

Ícones funcionais usam texto dos botões existente; as imagens têm alt vazio por serem decorativas.
