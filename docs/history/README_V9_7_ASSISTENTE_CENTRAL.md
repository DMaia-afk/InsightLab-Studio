# InsightLab Studio v9.7 — Assistente Central

- Menu Intelligence removido. O chat flutuante é o assistente principal.
- Central de IA foi movida para Configurações.
- O assistente oferece consultas locais ou via LangChain, criação de dashboards mediante confirmação, propostas de melhoria gerando uma cópia e registro de eventos mediante formulário.
- Melhorias no Canvas ainda criam uma nova versão: não editam widgets existentes automaticamente.
- E-mail e outros conectores são pontos de extensão, não estão ativados.
- O importador e o motor de widgets ainda não suportam qualquer CSV arbitrário sem normalização.
